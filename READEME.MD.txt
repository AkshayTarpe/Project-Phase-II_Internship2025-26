# 🌱 Personal Carbon Footprint Application

A full-stack web application that helps users monitor, analyze, and reduce their carbon footprint through activity tracking, goals, badges, leaderboards, and sustainability-focused rewards.

---

## 📌 Features

### 👤 User Features
- User Registration & Login
- JWT Authentication
- Google & GitHub OAuth Login
- Personal Profile Management
- Carbon Footprint Tracking
- Carbon History Records
- Lifestyle Survey
- Sustainability Goals
- Achievement Badges
- Notifications
- Marketplace & Rewards
- Transaction History
- Leaderboard Rankings

### 🛠️ Admin Features
- Admin Dashboard
- User Management
- Block / Unblock Users
- Badge Management
- Marketplace Management
- Notification Management
- Leaderboard Monitoring
- Audit Logs
- Maintenance Mode Controls

## ⚙️ Prerequisites

Before running the project, install:

- Java 17+
- Maven 3.8+
- Node.js 18+
- npm
- PostgreSQL

---

## 🗄️ Database Setup

Create a PostgreSQL database:

```sql
CREATE DATABASE carbon_tracker;
```

Default configuration:

```properties
Database : carbon_tracker
Username : postgres
Password : root
```

Update credentials if needed in:

```properties
backend/src/main/resources/application.properties
```

---

## 🔧 Backend Setup

Navigate to backend directory:

```bash
cd backend
```

Install dependencies and run:

```bash
mvn spring-boot:run
```

Backend runs at:

```text
http://localhost:8080
```

### Build Backend

```bash
mvn clean package
```

Run generated JAR:

```bash
java -jar target/carbontracker-0.0.1-SNAPSHOT.jar
```

---

## 💻 Frontend Setup

Navigate to frontend directory:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm start
```

Frontend runs at:

```text
http://localhost:3000
```

## 📡 Important API Endpoints

### Authentication

```http
POST /api/auth/login
GET  /api/auth/me
```

### Users

```http
GET    /api/users
PUT    /api/users/{id}/block
PUT    /api/users/{id}/unblock
DELETE /api/users/{id}
```

### Carbon Logs

```http
GET  /api/carbon/logs
POST /api/carbon/logs
```

### Goals

```http
GET  /api/goals
POST /api/goals
```

### Badges

```http
GET  /api/badges
POST /api/badges/award/{userId}
```

### Marketplace

```http
GET    /api/marketplace/items
POST   /api/marketplace/items
PUT    /api/marketplace/items/{id}
DELETE /api/marketplace/items/{id}
```

### Notifications

```http
GET /api/notifications
POST /api/notifications
```

### Leaderboard

```http
GET /api/leaderboard
GET /api/leaderboard/weekly
```
